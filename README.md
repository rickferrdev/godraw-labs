# GoDraw Labs

A small learning project for drawing 2D shapes in Go.

The goal is to explore basic graphics programming and learn how to draw shapes using pixels and simple math.

## Features

- Draw circles
- Draw lines
- Draw rectangles
- Save images as PNG files

## Examples

Run an example with:

```bash
go run ./examples/circle
```

Other examples:

```bash
go run ./examples/line
go run ./examples/rect
```

Each example generates a PNG image in the current working directory.

## Project Status

This project is a work in progress, created for learning and experimentation.

More shapes and drawing features may be added over time.
